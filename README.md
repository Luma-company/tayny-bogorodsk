# Тайны старого Богородска

Квест по десяти достопримечательностям Ногинска на основе экскурсии «Тайны старого Богородска». Пешеходный маршрут строится по дорожкам и улицам через OpenStreetMap. Кнопка «Я на месте» открывает вопрос без проверки геопозиции.

Откройте `index.html` в браузере. Нажимайте «Я на месте», чтобы отвечать на вопросы по мере прохождения маршрута.
